העלאת PassCheck לטלפון 📱

מדריך צעד-אחר-צעד. אפשר לחזור לצ׳אט לקבלת הסבר, אך מפתחות וערכי סודות נשארים תמיד אצלך ומוזנים ישירות בממשקים המוגנים.

איך זה עובד: יש לנו "רובוט" בענן (GitHub) שבונה את האפליקציה ומעלה אותה ל-TestFlight (האפליקציה של אפל לבדיקת אפליקציות לפני חנות). כדי שהרובוט יורשה להעלות, צריך לתת לו "מפתח" מ-Apple. זה מה שנעשה כאן.
מה שהעוזר יכול לעשות בשבילך: להסביר את השלבים ולקרוא תוצאות שאינן מכילות סודות. את קובץ המפתח והערכים שלו אתה שומר ומזין בעצמך בלבד.

1 ליצור מפתח ב-App Store Connect

  1. היכנס ל-appstoreconnect.apple.com (עם ה-Apple ID שלך).
  2. למעלה: Users and Access → הלשונית Integrations.
  3. תחת App Store Connect API → לחץ + (Generate API Key).
  4. שם: CI · Access: App Manager → Generate.
  5. הורד את הקובץ .p8 (כפתור Download) ושמור אותו מיד בכספת סיסמאות או באחסון מוצפן שבשליטתך.
⚠️ את קובץ ה-.p8 אפשר להוריד פעם אחת בלבד. לעולם אל תעלה אותו לצ׳אט, ל-Git, למסמך או לשירות שיתוף. אל תדביק בצ׳אט גם את תוכנו או את גרסת ה-base64 שלו.
מה אפשר לכתוב בצ׳אט: רק שהשלב הושלם. אין לשלוח את ה-Key ID, ה-Issuer ID, קובץ ה-.p8 או ערך סוד כלשהו.

2 להמיר את הקובץ מקומית אתה עושה

ב-PowerShell במחשב שלך הרץ: [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\AuthKey_XXXX.p8")). העתק את הפלט ישירות לשדה הסוד ב-GitHub. אל תדביק את הפלט בצ׳אט ואל תשמור אותו בקוד או במסמך.

3 להוסיף 3 סודות ל-GitHub

  1. היכנס ל-github.com/hvkh22-sudo/check123
  2. Settings → בצד: Secrets and variables → Actions.
  3. פתח Settings → Environments → testflight → Environment secrets, והוסף שלושה ערכים בעצמך. אל תעביר אותם דרך צ׳אט:
Name: ASC_KEY_ID Value: (ה-Key ID) Name: ASC_ISSUER_ID Value: (ה-Issuer ID) Name: ASC_KEY_P8 Value: (פלט ה-base64 שיצרת מקומית)
הערכים נשארים רק בינך, Apple וה-Environment המוגן ב-GitHub. העוזר אינו צריך לראות אותם.

4 להריץ את ההעלאה

  1. ב-github.com/hvkh22-sudo/check123 → לשונית Actions.
  2. בצד שמאל בחר iOS CI → לחץ Run workflow → שוב Run workflow (הכפתור הירוק).
אני אקרא את התוצאה בשבילך ואגיד אם הצליח או אתקן שגיאה. פשוט כתוב לי "הרצתי".

5 להתקין על ה-iPhone

  • אחרי שההעלאה מצליחה, ב-App Store Connect → TestFlight → הוסף את עצמך כ-Internal Tester.
  • בטלפון: התקן את האפליקציה TestFlight מהחנות, קבל את ההזמנה, והתקן את PassCheck.
  • 🎉 האפליקציה על הטלפון שלך — נבדוק את דיוק המנוע יחד.

נתקעת בשלב כלשהו?

אפשר לצלם את המסך או להעתיק שגיאה לצ׳אט רק לאחר שמסתירים מפתחות, ערכי סודות, כתובות אימייל ומזהים אישיים. לעולם אין לצרף את מסך ה-Environment secrets.
